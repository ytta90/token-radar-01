How the value is worked out

Implied value = TVL × category multiple × growth × maturity. The category multiple is the median market-cap / TVL of the token-bearing protocols in the same category, shrunk toward the global median so a thin category cannot set the price alone; categories with fewer than three comparables use the global median. Growth is the 7-day change, clamped to −50% … +100% and weighted 0.6×. Maturity rises from 0.6 for a new protocol to 1.0 at three years. The implied value never exceeds three times TVL.
